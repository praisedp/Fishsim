# Classic Programming Problems

Challenge yourself with these famous computer science problems to improve your algorithmic thinking, data structures knowledge, and Python programming skills.

---

# 🟢 Easy: The Warm-Ups

These problems are commonly used as introductory coding interview questions.

## 1. FizzBuzz

### Problem Statement
Write a program that prints the numbers from **1 to 100**.

- For multiples of **3**, print `"Fizz"` instead of the number.
- For multiples of **5**, print `"Buzz"` instead of the number.
- For numbers that are multiples of **both 3 and 5**, print `"FizzBuzz"`.

### Skills Tested
- Control flow
- Conditional statements
- Modulo operator (`%`)

---

## 2. Two Sum

### Problem Statement
Given an array of integers `nums` and an integer `target`, return the **indices** of the two numbers such that they add up to `target`.

### Example

Input:

```text
nums = [2, 7, 11, 15]
target = 9
```

Output:

```text
[0, 1]
```

### Skills Tested
- Arrays
- Hash maps (Python dictionaries)
- Time complexity optimization

---

## 3. Fibonacci Sequence

### Problem Statement
Write a function that returns the **n-th Fibonacci number**.

The Fibonacci sequence is defined as:

```text
0, 1, 1, 2, 3, 5, 8, 13, ...
```

Each number is the sum of the two preceding numbers.

### Skills Tested
- Loops
- Recursion
- Memoization
- Dynamic programming basics

---

# 🟡 Medium: The Thinkers

These problems require deeper algorithmic understanding.

## 4. Tower of Hanoi

### Problem Statement
You have:

- Three rods
- A stack of disks of different sizes

Move the entire stack from the source rod to the destination rod following these rules:

1. Move only one disk at a time.
2. Only the top disk can be moved.
3. A larger disk cannot be placed on top of a smaller disk.

### Skills Tested
- Recursion
- Divide-and-conquer thinking
- Algorithmic pattern recognition

---

## 5. 0/1 Knapsack Problem

### Problem Statement
You are given:

- A set of items
- Each item has a weight and value
- A knapsack with a maximum weight capacity

Determine the maximum total value that can be obtained without exceeding the weight limit.

Each item can either be:

- Taken (`1`)
- Not taken (`0`)

### Skills Tested
- Dynamic programming
- Optimization
- Recursive problem solving

---

## 6. Conway's Game of Life

### Problem Statement
Implement a simulation of Conway's Game of Life.

Each cell in a grid is either:

- Alive
- Dead

The grid evolves according to rules based on neighboring cells:

1. Underpopulation
2. Survival
3. Overpopulation
4. Reproduction

### Skills Tested
- 2D arrays (matrices)
- Simulation
- State management

---

# 🔴 Hard: The Architect Challenges

These are historically important and computationally challenging problems.

## 7. N-Queens Problem

### Problem Statement
Place **N queens** on an **N × N chessboard** so that no two queens attack each other.

Queens attack along:

- Rows
- Columns
- Diagonals

Return one or all valid arrangements.

### Skills Tested
- Backtracking
- Constraint satisfaction
- Search algorithms

---

## 8. Traveling Salesperson Problem (TSP)

### Problem Statement
Given:

- A list of cities
- Distances between every pair of cities

Find the shortest possible route that:

1. Visits every city exactly once.
2. Returns to the starting city.

### Skills Tested
- Graph theory
- Permutations
- Optimization
- NP-hard problem solving

---

## 9. Sudoku Solver

### Problem Statement
Given a partially completed **9 × 9 Sudoku board**, write an algorithm that fills the board according to Sudoku rules.

Rules:

- Each row contains digits 1–9 exactly once.
- Each column contains digits 1–9 exactly once.
- Each 3 × 3 subgrid contains digits 1–9 exactly once.

### Skills Tested
- Backtracking
- Deep recursion
- Matrix traversal
- Constraint propagation
